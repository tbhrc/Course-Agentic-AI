# Course — Agentic AI

A practical, build-first course for learning how to **operate, control, build, test and improve useful AI agents and agentic systems**.

This repository is the **canonical general course**. Individual learner repositories may adapt examples, pace and domain projects while preserving the core learning outcomes.

## Start here — give this repository to your AI

Copy this prompt into ChatGPT, Codex, Claude, or another capable agent environment:

> Open and work from https://github.com/tbhrc/Course-Agentic-AI. Read the root AGENTS.md first. Act as my practical Agentic AI learning coach. Start with course/00-start-here.md and follow the course in order. Adapt the pace to my demonstrated ability. Do not merely explain concepts: make me perform the exercises, create durable artifacts, inspect changes, debug failures, verify outcomes, and explain what I learned back to you. Use examples from my own domain whenever possible. For current product-specific facts, verify authoritative live sources.

## What makes this course different

The course is based on operating patterns proven in real AI-agent work:

- **one capable agent before multi-agent complexity**;
- **project instructions before giant one-off prompts**;
- **GitHub as durable working memory and change evidence**;
- **Skills for reusable HOW**;
- **SB1-style smart-agent-first Skill design**;
- **KA1 / KISSS simplification before adding machinery**;
- **Lessons that change future behaviour, not lesson logs for their own sake**;
- **one canonical owner/source of truth**;
- **deterministic helpers only when they provide real leverage**;
- **verification as part of execution**;
- **real security boundaries without approval theatre**.

See [METHODOLOGY.md](METHODOLOGY.md).

## Learning path

```text
AI mental models
→ operate one agent well
→ project instructions / AGENTS.md
→ files + Git + GitHub
→ reusable Skills
→ Codex and coding literacy
→ tools + APIs + MCP
→ context + state + memory + data
→ debugging + evals + safety
→ smallest useful architecture
→ real capstone agent
→ multi-agent systems
→ production thinking
```

See [COURSE.md](COURSE.md) for the complete roadmap.

## Personalized learner tracks

The canonical course stays general.

A learner-specific repository may add:

- personal background and technical level;
- preferred analogies;
- domain projects;
- pace adjustments;
- personal exercises;
- capstone specialization.

Example: [Course-Andre-Venter](https://github.com/tbhrc/Course-Andre-Venter).

Personalization must not become a competing source of truth for the general curriculum.

## Course doctrine

**Learn by operating and building.**

A concept should become an action, file, diff, Skill, test, tool call, diagnosis or verified result as quickly as practical.

The course is complete when the learner can independently take a real problem and build a reliable agentic solution—not when every page has merely been read.
