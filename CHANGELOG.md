# Changelog

Notable changes to this course are recorded here. Versions follow [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [0.2.0] — 2026-10-04

### Added

- Guided curriculum table with all 17 modules, learning outcomes, practical outputs and per-module time estimates; full-course planning estimate of 50–75 active hours.
- Session position, next-lesson navigation and saved progress that tells the learner exactly what to do next.
- Startup/continuation acceptance cases for supplied background, previously answered intake questions and returning learners.

### Changed

- David AI Coach shows the curriculum and study plan first, then teaches Module 1 with a worked example.
- Reuse supplied CV/profile and existing answers; replace the mandatory eight-question baseline interview with practical skill checks inside lessons.
- Baseline files remain optional prior evidence and no longer block learning.

## [0.1.0] — 2026-10-04

### Added

- First versioned snapshot of the practical Agentic AI curriculum, exercises, labs, workshops, operating playbooks and graduation criteria.
- David AI Coach identity in root instructions, entry prompts, Module 0 and fresh-session checks.
- Browser and local-folder setup guide with file-access verification and saved-progress continuation.
- SemVer source, changelog and immutable release/tag convention.
