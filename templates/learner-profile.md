# Learner Profile — <Name>

## Purpose

This file is the durable learner-context owner for this personalized course.

Use it to adapt pace, examples, exercises and capstone choices. It is not a CV and it does not replace an honest baseline of current ability.

## Coaching summary

Summarize only the background that materially changes how this learner should be taught.

## Evidence

### Verified evidence

Record certificates, portfolio items, inspected work or demonstrated capabilities that are genuinely supported by evidence.

### Learner-declared context

Record relevant self-reported experience, preferences, interests and current goals.

### Demonstrated current capability

Update this only from actual course performance or another direct demonstration.

Examples:

- Git/GitHub;
- coding;
- JSON/HTTP;
- APIs;
- MCP;
- agent design;
- debugging/evals.

### Unknown / unproven

List important skills that still need to be tested.

Do not infer a skill merely from adjacent professional or technical experience.

## Useful teaching bridges

List familiar systems, workflows or concepts that can help explain new Agentic AI ideas.

Use analogies only when they genuinely clarify the concept. Gradually remove the analogy as the learner gains direct understanding.

## Current learning priorities

Record the learner's current practical goals and the problems that would make the course useful now.

## Capstone directions

List a small number of plausible real-world capstone directions.

The coach should still choose the final problem **with** the learner, based on a real current need.

## Coaching strategy

### Move quickly through

List concepts the learner can already demonstrate or map easily.

### Spend real time on

List genuinely new or unproven capabilities.

## Privacy rule

Store only the minimum information needed for coaching.

Do not add unnecessary sensitive data such as:

- government identity/passport numbers;
- employee/account numbers;
- passwords or credentials;
- private contact details;
- medical information;
- unrelated private records.

This is especially important when the learner repository is public.

## Maintenance rule

Update this file only when new evidence materially changes coaching decisions.

A learner profile guides teaching; the learner's current demonstrated performance remains the final evidence of capability.
